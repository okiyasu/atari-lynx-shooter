## 要求1: BGM/SFX出力ゲイン

論理BGMと全7種SFXの**MIKEY出力音量だけ**を一律75%へ下げる。music/SFX table、note、wave、duration、priority、SFX終了/死亡同期、envelopeの意味を変更しない。

- channel A/C（BGM）およびB（全SFX）にhardwareへ書く直前の出力volumeへ`floor(volume * 3 / 4)`を適用する。元volumeが非zeroで計算結果0なら1を出す。`0→0, 1→1, 2→1, 3→2, 4→3, 31→23`を固定する。
- channel DのADPCMタイトル/ゲームオーバー音声はgainを**一切**適用しない。データ、rate（Timer 3 backup 125、126 us、7,936.508 Hz）、DAC列も既存タイトルvoiceから変えない。
- logical table accessorと既存のtable固定回帰はfull-scaleの元データを検査し続ける。gainはoutput stageの別責務とし、host側で式・境界値、BGM/Bass/SFX全経路、D非適用を回帰可能にする。`scripts/verify-audio-gearlynx.py`等のMIKEY期待値は75%へ更新・実測する。

## GAME OVER状態機械

- 最終ライフの爆発SFXが実際に完了した後、従来どおりGAME OVER画面へ遷移し、同時に一度だけゲームオーバー音声を開始する。非最終死亡では絶対に開始しない。
- 再生中は`game_over`画面を維持し、A/Bを無視する。画面の`A/B TO TITLE`案内は完了まで表示しないか、入力無効を明示する。
- 音声完了までは`restart_armed=0`を保つ。完了後にのみ従来どおりrelease→pressでタイトルへ戻る。終了時にFIREが押下済みでもタイトルへ遷移しない。
- title/game-overのpending/completeを別状態としてgame host回帰に入れ、完了一回だけ、重複完了、held input、Timer 3/D排他、final death branchを検証する。
