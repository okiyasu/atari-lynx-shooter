## 確定仕様

### 固定4敵への状態移行

- `GameEnemy`相当の構造体と `GAME_MAX_ENEMIES 4u` の固定配列を共有ロジックへ導入する。各敵は矩形、活動状態、敵種別、移動パターン、基準Y、移動間引きカウンタ、位相、方向、発射カウンタを独立に持つ。
- 既存の単一敵フィールドは4敵へ安全に移行する。互換性のためだけの二重状態を残さず、ゲームロジック・描画・テストを配列の正本へ統一する。
- 初期化と死亡後の再出撃では4スロットすべてを活動状態とし、Xを順に140、170、200、230、基準Yを47、23、70、38とする。種別はスロット番号 `% 2`、パターンはスロット番号 `% 3` とし、初期状態でScout/直進、Saucer/上下波形、Scout/急降下折返し、Saucer/直進を構成する。
- Xが160以上の画面外右側にある敵は左へ1px移動するだけとし、描画、垂直移動、発射、自機弾命中、自機接触、左端損傷の対象外にする。Xが159以下になった次の通常処理から画面内敵として扱う。
- 既存3パターンの数値を維持する。直進は左1px/更新、上下波形は左1pxかつ3更新に1px・基準上下6pxの三角波、急降下折返しは左1pxかつ2更新に1px・基準下12px往復。YはHUD下端から画面下端へクランプする。

### 撃破と再配置

- 自機弾は既存どおり固定3発・右4px/更新・3x2矩形とする。各活動弾を1回だけ移動した後、画面内敵をスロット0から3の順に検査し、最初にAABBが重なった1体だけを撃破する。1発で複数敵を撃破しない。
- 同一更新に別々の自機弾で複数敵を撃破することは許可し、各撃破で100点を加える。同じ敵が再配置後に同一更新でもう一度命中しないよう、再配置済みスロットを明示的に除外する。
- 撃破されたスロットだけを再配置する。グローバルな決定的 `respawn_sequence` を1増やし、Xは `180 + slot * 16`、種別は `(respawn_sequence + slot) % 2`、パターンは `(respawn_sequence + slot) % 3`、基準Yは `13 + ((respawn_sequence + slot) * 17) % 78` とする。位相、方向、移動カウンタ、発射カウンタは新しい設定に合わせて初期化する。
- 自機弾命中処理は敵移動・敵発射・自機損傷より先に行う。命中再配置された敵はその更新では移動・発射・接触しない。他の敵と既存敵弾の更新・損傷判定は続ける。「命中優先」は命中した対象に適用し、無関係な別の損傷源まで無効化しない。

### 敵種別ごとの発射と固定6敵弾

- `GAME_MAX_ENEMY_BULLETS 6u` の固定配列を追加する。敵弾は2x2矩形、左へ2px/通常更新。描画色は自機弾と区別できる既存16色内の固定色を選び、矩形TGI描画とする。
- Scoutの発射間隔は画面内で90通常更新、Saucerは60通常更新。データテーブルまたは等価な設定で種別と間隔を分離する。
- 敵の発射カウンタ初期値は `(slot * 15) % interval`。敵が画面内で、通常状態の更新対象であるときだけ1増やし、間隔へ到達した更新で発射を試みて0へ戻す。
- 発射時は敵弾スロットを0から5の順に探索する。空きがあれば敵の左端、縦中央付近に1発生成する。X=159の敵から生成する場合は敵弾の右端が画面外へ出ないよう生成Xを158へ制限する。空きがなくてもカウンタは0へ戻し、空きができた直後に毎更新再試行する集中発射を防ぐ。
- 更新順は「既存敵弾の移動・画面外消去」を「敵の移動・新規発射」より前にする。これにより新規敵弾は生成更新には動かず、次の通常更新から左へ2px動く。
- 敵弾はXが2未満で次移動により左外へ出る場合に非活動化する。活動敵弾が自機へAABBで重なれば当該弾を消し、損傷候補とする。

### 損傷、爆発、再出撃、無敵、GAME OVER

- 1通常更新の最後に、画面内敵の自機接触、敵のX=0到達、敵弾の自機接触をまとめて判定する。同じ更新に何件成立しても `begin_player_death` 相当は1回だけ呼び、残機を1だけ減らす。自機へ重なった敵弾は損傷源が複数でもすべて消去してよい。
- 通常被弾開始では既存どおり全自機弾を消す。敵弾と4敵はその位置で32更新の爆発中凍結し、重複被弾しない。背景、得点、入力、発射カウンタ、アニメーションを含むAPS-004の凍結条件を維持する。
- 非最終残機の爆発完了時は、自機を `(10,48)`、4敵を上記初期編成へ戻し、全敵弾を消去する。得点と2層背景状態は保持し、自機弾なし、クールダウン0、正確な60通常更新の無敵で再開する。
- 無敵中に敵本体、X=0、敵弾のいずれかが損傷条件を満たしても残機を減らさず、死亡へ入らず、無敵時間を延長しない。当該敵弾を含む全敵弾を消去し、4敵編成と敵発射カウンタを初期配置へ戻して再接触を防ぐ。
- 最終残機は4敵・敵弾を含む通常状態を32更新凍結し、爆発完了後のみGAME OVERへ入る。GAME OVER中も全敵・全敵弾・発射カウンタを凍結する。
- A/Bを押しっぱなしでは再開始しない。解除後の再押下による `game_init` 相当で、4敵、全敵弾、発射カウンタ、出現列、死亡、無敵を含むすべてを初期値へ戻し、再開始更新には発射しない。

### 描画

- `src/main.c` は4敵をスロット順に描画し、既存の敵種別2種・2フレームの自作マスクを再利用する。画面外右側は描画しない。
- 6敵弾は活動中だけ2x2矩形で描画する。爆発中は凍結した敵と敵弾を描画し、通常自機を4段階爆発へ置換する。GAME OVER時の既存表示を維持する。
- TGIへ画面外座標を渡さず、既存のクリップ済み水平ラン・矩形構造を維持する。
