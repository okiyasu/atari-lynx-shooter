## 実装設計

### 1. 決定的な2層背景

- 背景は固定座標表の星2層とし、乱数、浮動小数、フレームごとの動的配列操作を使わない。
- 遠景オフセットは4ゲームフレームに1px、近景オフセットは2ゲームフレームに1px左スクロール相当で進め、160pxでラップする。オフセットと間引きカウンタは`GameState`に持たせ、ホストテスト可能にする。
- 描画用の固定星は遠景8〜12個、近景6〜8個を目安とし、すべてHUD下端〜画面下端に配置する。遠景は暗い1px、近景は明るい1〜2pxとし、色・大きさ・速度で層の違いが分かるようにする。
- ラップは符号なしアンダーフローに依存せず、明示的な加減算と境界分岐で座標を0〜159に保つ。

### 2. 自作ピクセルキャラクター

- 自機は8x6、敵は8x8の現行AABBを維持する。描画は矩形全体の塗りつぶしから、1行1byteの1bitマスクから作る自作形状へ置き換える。
- 自機1種、敵2種（Scout系とSaucer系を目安）を用意する。敵2種は色だけでなくシルエットが明確に異なり、コードレビューでマスク差を確認できるようにする。
- 自機と敵2種はそれぞれ2フレームのマスクを持ち、8ゲームフレームごとに切り替える。同一キャラクターの2フレームは完全同一にしない。
- マスク配列は`src/main.c`内の`static const unsigned char`でよい。ホスト側でマスク自体を検証する構成を選ぶ場合のみ、C89互換の新規共有ソースとヘッダへ分離し、`Makefile`のROM・ホスト両方の依存関係を正しく更新する。
- マスク描画は各行を左から走査し、連続した1bitを1回の`tgi_bar(x0, y, x1, y)`として描画する。全1bitごとの`tgi_setpixel()`呼び出しは避ける。弾は現行の3x2矩形のまま維持する。

### 3. データ駆動の敵移動

- 共有ロジックに、最低でも水平進行速度・垂直更新間隔・垂直幅・挙動種別を持つ固定の移動設定テーブルを置く。移動種別を配列インデックスで選び、数値を分散した条件分岐に直書きしない。
- パターン0=直進: Xを毎フレーム1px左へ移動し、Yは基準座標を維持する。
- パターン1=上下波形: Xを毎フレーム1px左へ移動し、3フレームに1px、基準Yの上下最大6pxまで三角波で往復する。
- パターン2=急降下折返し: Xを毎フレーム1px左へ移動し、2フレームに1px、基準Yから下へ最大12pxまで降下した後は基準Yまで上昇して繰り返す。
- 各パターンのY範囲は、敵の基準Yと幅にかかわらず`GAME_HUD_HEIGHT`以上、`GAME_SCREEN_HEIGHT - GAME_ENEMY_HEIGHT`以下にクランプする。符号なし値をアンダーフロー/オーバーフローさせない。
- 敵種別は`respawn_sequence % 2`、移動パターンは`respawn_sequence % 3`と等価の決定表で循環させる。初期のsequence 0は敵種0・直進、sequence 1は敵種1・上下波形、sequence 2は敵種0・急降下折返し、sequence 3は敵種1・直進となる。
- 初期化と命中/残機喪失後の再配置で、敵の基準Y、移動フェーズ、垂直方向を初期値へ戻す。現行の決定的Y再配置列は維持してよい。

### 4. APS-002との統合・更新順序

- `game_update()`のフレーム順序は「GAME OVER中の解除/再押下判定 → 背景オフセットとアニメーションカウンタ → 自機入力・発射・弾更新 → 弾命中なら得点加算・敵再配置してreturn → 敵パターン移動 → 自機接触/左端到達」とする。
- 弾命中の100点、命中フレームの再配置後敵移動省略、同時被弾条件で残機1だけ減少、非最終被弾後の得点・自機位置維持、全弾消去を維持する。
- GAME OVER中は、APS-002の状態に加え、遠景/近景オフセット、間引きカウンタ、アニメーションカウンタ、敵パターンフェーズ/方向も凍結する。再開始ではこれらを含む全状態を初期化し、再開始フレームに弾を発射しない。

既存APS-002の37チェックの意味を維持し、少なくとも次を明示的に検証する。APS-003の正当な新仕様により既存の座標期待値を更新する場合は、テストの意味を削除しないこと。

- 初期背景オフセット/カウンタが0、近景が2フレームで1px、遠景が4フレームで1px進み、速度差がある。
- 両背景オフセットが159の次に0へラップし、符号なし値のオーバーフローに依存しない。
- 8ゲームフレームごとにアニメーションフレームが0/1で切り替わる。
- 初期は敵種0・直進、sequence 1で敵種1・上下波形、sequence 2で敵種0・急降下折返し、sequence 3で敵種1・直進と、種別と2状態/パターンが3状態で独立に循環する。
- 直進は複数フレーム後もY不変でXのみ1px/フレーム左へ進む。
- 上下波形は3フレームごとの1px垂直移動、基準Y±6pxの折返し、画面上下端のクランプを決定的な座標列で検証する。
- 急降下折返しは2フレームごとの1px垂直移動、基準Yから下へ12pxの折返し、基準Yへの復帰を検証する。
- 命中と残機喪失の両方で敵種別/パターン/基準Y/フェーズ/方向が次の決定状態へ正しく再初期化される。
- 弾命中が同フレームのパターン移動・接触・左端到達より優先され、100点加算と再配置のみ発生する。
- GAME OVER中は背景オフセット/カウンタ、アニメーションカウンタ、敵フェーズ/方向も複数フレーム凍結し、A/B解除後の再押下で初期値へ戻る。APS-002の全3弾凍結も維持する。
