## 今回の依頼(T0のみ・T0-3は対象外)

MAIN領域RAM捻出のT0を実施する。Phase 3R本体には一切着手しないこと。

### T0-1 + T0-2: 死にモジュール2件をROMリンクから除外

- `Makefile:21` の `COMMON_ROM_OBJECTS` から `build/ima_adpcm.o`(1,090B)と `build/pcm_stream.o`(328B)を除外する
- 除外はリンク対象からのみ。`src/ima_adpcm.c` 等のソースファイル自体・`tests/test_ima_adpcm.c` 等の独立ホストテストは削除・変更しない(設計書§4記載の通り、mapのImports listに `_ima_adpcm_*`/`_pcm_stream_*` の参照が1件もないことを確認済み。実音声再生は `title_voice_stream.s` の独自ドライバが担当)
- `pcm_stream.o` は `.interruptor pcm_stream_irq` によりIRQハンドラだけがcondes経由で生存していた。除外後はこのinteruptorテーブルからも消えるはずなので、mapで確認すること

### T0-3(診断アセット削除)は今回やらない

- APS-053のタイトル診断表示(`L/R BIT TEST` literal、`"A V 0 5 6"` 表示コード)は**削除しないこと**。実機での文字化け修正確認(v0.53.7)の結果をユーザーからまだ受け取っていないため保留
- 誤って着手しないよう明記する。次版で診断終了確認後に別途依頼する

## 検収条件(設計書§4より)

1. `build/asteroid-patrol.map` と `build/asteroid-patrol-cadence.map` の両方で `ima_adpcm.o`/`pcm_stream.o` が消滅していること、Imports listに `_ima_adpcm_*`/`_pcm_stream_*` が存在しないこと
2. タイトル音声・GAME OVER音声の再生に異常がないこと(Gearlynxで実際に再生確認。interruptorテーブル変化の影響有無を耳で確認)
3. `make clean && ./scripts/verify.sh` 全PASS(既存のsmoke/perf/音声回帰含む)
4. `GAME_VERSION_STRING` を現在の `0.53.7` から更新すること(ROM生成のたび必ず上げるプロジェクトルール)
5. release/cadence両方のMAIN余剰バイト数(mapのSegment list実測値)を報告すること。「入ったはず」ではなく実測値を提示すること(v2 §7の報告様式)
