## 背景

v048回答のPath B設計(HUD 8pxピッチ化、1セル=1バイト完全所有でRMWを排除)を実装した。ユーザーは視覚変更(字間1px→3px、HUD幅120px→160px全幅)と、gate(d)基準緩和(release≥512Bのみ拘束、cadence≥128Bへ緩和)を承認済み。

## 実測結果: 目標にわずかに届かず

| 構成 | v048(6pxピッチ、対策前) | v049(8pxピッチ、Path B実装後) | 目標 |
|---|---:|---:|---:|
| release余剰 | 182B | **484B** | ≥512B(28B不足) |
| cadence余剰 | 46B | **348B** | ≥128B(達成) |

static_layer.o CODE: HEAD(2,787B)→v048 6pxピッチ(3,563B、+776B)→v049 8pxピッチ(3,282B、+495B)。Fable5の推定削減(-400〜-480B、release余剰580〜680B見込み)に対し、実測削減は450B程度に留まり、release余剰484Bで目標(≥512B)まで28B届いていない。

## 実施した実装(Path B設計通り)

- `write_hud_cell_row`+`write_hud_cell`(6pxピッチ、計369B)を単一の`write_hud_cell`に統合、RMWを排除(セルは1バイト完全所有、`*dst = (unsigned char)(bits << 3)`の単純代入)
- `hud_cell_byte_offset`テーブル・switch分岐を全廃
- `hud_rebuild_skeleton`: 各行individually memsetではなく、7行分+終端(148バイト)を1回の`memset`で一括クリアしてからヘッダバイトのみ書く形に変更
- `append_hud`のスコア復元コピー・`hud_prev_text`更新コピーを`memcpy`化

## 自己判断で試して逆効果だった追加最適化(3件、いずれも元に戻し済み)

念のため報告する。generated assemblyを見ずにC言語レベルで「軽くなるはず」と判断したところ、3件とも逆にコードサイズが増加した(v046以来の教訓「C言語レベルの見積もりは信頼できない」を自ら再確認する形になった):

1. `write_hud_cell`内で`index*STATIC_LAYER_FONT_HEIGHT`の乗算をループ外に汲み出し、ポインタ歩行に変更 → **+43B**(36,050→36,093)
2. スコア復元の`memcpy(text+9, hud_prev_text+9, 5u)`を手動ループに戻す → **+19B**(36,050→36,069)
3. `hud_prev_valid==0`時の全再構築ループと通常差分ループを、`hud_prev_text`を`0xFF`埋めして単一ループに統合 → **+62B**(36,050→36,112)

いずれも生成アセンブリを見ずに試した結果であり、原因分析はしていない(v046ルール「生成アセンブリベースの事前見積もり」を今回も部分的にしか実践できなかった)。

```c
static void hud_rebuild_skeleton(void)
{
    unsigned char row;
    unsigned char* p = HUD_DATA;

    memset(p, 0, (unsigned int)HUD_ROW_BYTES * STATIC_LAYER_FONT_HEIGHT +
        1u);
    for (row = 0u; row < STATIC_LAYER_FONT_HEIGHT; ++row) {
        *p = (unsigned char)HUD_ROW_BYTES;
        p += HUD_ROW_BYTES;
    }
}

static void write_hud_cell(unsigned char cell, char glyph)
{
    unsigned char row;
    unsigned char index;
    unsigned char* dst;

    index = text_font_index(glyph);
    dst = HUD_DATA + 1u + cell;
    for (row = 0u; row < STATIC_LAYER_FONT_HEIGHT; ++row) {
        *dst = index < STATIC_LAYER_FONT_COUNT ?
            (unsigned char)(static_layer_font_bits[index *
                STATIC_LAYER_FONT_HEIGHT + row] << 3) : 0u;
        dst += HUD_ROW_BYTES;
    }
}

static void append_hud(const GameState* game)
{
    char text[HUD_TEXT_LENGTH + 1u];
    unsigned char i;
    unsigned int timer_value;

    if (game->score != hud_prev_score) {
        unsigned long score_value = game->score;
        for (i = 5u; i != 0u; --i) {
            text[8u + i] = (char)('0' + score_value % 10ul);
            score_value /= 10ul;
        }
        hud_prev_score = game->score;
    } else {
        memcpy(text + 9, hud_prev_text + 9, 5u);
    }
    timer_value = game->phase_timer;
    for (i = 4u; i != 0u; --i) {
        text[3u + i] = (char)('0' + timer_value % 10u);
        timer_value /= 10u;
    }
    text[0] = 'S'; text[1] = (char)('0' + game->stage); text[2] = ' ';
    text[3] = game->phase == GAME_PHASE_NORMAL ? 'N' :
        game->phase == GAME_PHASE_BOSS ? 'B' :
        game->phase == GAME_PHASE_STAGE_INTRO ? 'I' :
        game->phase == GAME_PHASE_WARNING ? 'W' :
        game->phase == GAME_PHASE_STAGE_CLEAR ? 'C' : 'A';
    text[8] = ' ';
    text[14] = ' '; text[15] = 'L';
    text[16] = (char)('0' + game->lives); text[17] = ' '; text[18] = 'W';
    text[19] = (char)('0' + game->weapon_level); text[20] = '\0';

    if (hud_prev_valid == 0u) {
        hud_rebuild_skeleton();
        for (i = 0u; i < HUD_TEXT_LENGTH; ++i) write_hud_cell(i, text[i]);
        hud_prev_valid = 1u;
    } else {
        for (i = 0u; i < HUD_TEXT_LENGTH; ++i) {
            if (text[i] != hud_prev_text[i]) write_hud_cell(i, text[i]);
        }
    }
    memcpy(hud_prev_text, text, HUD_TEXT_LENGTH + 1u);

    append_scb(HUD_DATA, 0, 2, WHITE);
    SCBS[scb_count - 1u].sprctl1 = (unsigned char)(LITERAL | REHV);
    append_scb(static_layer_clear_data, 0, GAME_HUD_HEIGHT - 1u, NEAR_STAR);
}
```
