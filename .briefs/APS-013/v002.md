## 純Cサウンド状態

1. `include/sound.h`と`src/sound.c`へ厳格C89の純C固定シーケンサを新設する。固定長ステップに音程ID、長さ、音量、波形種別だけを持たせ、BGM/SFXカーソル、残り更新、固定1件保留、論理出力（active/note/volume/wave）を公開する。乱数、浮動小数、動的確保、時刻依存は禁止。
2. Stage 1は遅い宇宙アルペジオ、Stage 2は速い上昇飛行モチーフ、Stage 3は低音と休符が多い洞窟モチーフ。外部曲を参照しない短い自作ループとし、テンポ・音域・音型の差を固定表とテストで示す。
3. `game_init()`でStage 1曲頭。INTRO/NORMAL/WARNING/BOSS/STAGE CLEARでは同Stageの曲位置を維持する。Stage 1/2 CLEAR後の`stage++`で次曲の曲頭。死亡32更新だけBGMカーソルを凍結するがSFXは進め、再出撃後は死亡開始時の位置から再開する。通常SFX中はBGMカーソルを無音で進め、SFX終了時点のBGMへ戻す。GAME OVER/ALL CLEARで停止、完全再開始でStage 1曲頭。
4. SFXの集中発火点:
   - 射撃: NORMAL/BOSSの成功した1斉射だけ。失敗、cooldown、非戦闘、再開始押下は無音。
   - 敵撃破: 通常敵命中撃破と小惑星破壊。1更新の複数撃破は1回に集約。
   - 自機爆発: `begin_player_death()`の実損傷だけ。無敵中リセットと死亡中は再発火なし。
   - アイテム取得: AABBで実消費した時。Lv3でも鳴らし、生成時は無音。
   - WARNING: `enter_phase(GAME_PHASE_WARNING)`。通常境界と境界死亡後の遅延遷移を同じ集中点で扱う。
   - Boss撃破: HP0確定/得点加算時に一度。
   - STAGE CLEAR: `enter_phase(GAME_PHASE_STAGE_CLEAR)`で一度。
5. 優先度は射撃1 < 敵撃破2 < アイテム取得3 < WARNING 4 < 自機爆発5 < STAGE CLEAR 6 < Boss撃破7。同一以上の要求はactiveを破棄し、新SFXを先頭から開始する。同一IDの再要求も再始動する。ただしゲーム統合側で同一更新の複数敵/小惑星撃破は1要求へ集約する。低優先度要求は破棄する。
6. 唯一の例外として、activeがBoss撃破7の間に来るSTAGE CLEAR 6だけは専用の固定1件保留へ冪等に保存し、Boss撃破終了後に先頭から一度再生する。他の低優先度音を保留しない。Boss撃破+STAGE CLEARの合計長は120更新未満、自機爆発は32更新以下にする。
7. GAME OVER/ALL CLEAR成立、Stage切替、完全再開始はactive SFXと保留を破棄する。Boss→CLEAR連鎖が120更新内に完了し、通常のStage切替/ALL CLEARで切断されないことをテストする。早期returnを含む全phaseでサウンドtick/停止が欠落しない構造にする。
8. `GameState`に`SoundState`を統合するか同等の公開観測境界を設け、ゲーム統合テストから同じ本番ロジックを検証する。テスト専用別実装は禁止。

## Lynx/cc65バックエンド

- cc65 2.19の`lynx_snd_*`はTimer 7を240Hz IRQ化し独自ストリームを使うため呼ばない。純C 75Hz状態を正本にする。
- `src/main.c`だけに直接バックエンドを置き、`game_update()`後・描画前に反映する。`MIKEY`構造体はvolatileでないため、`volatile unsigned char`の8-bitアクセスを使う。
- 初期化時にcrt0のmute値を解除する`MSTEREO`（`0xFD50`）=0を一度設定し、channel AのVOL/CTLAを0にする。以後はchannel A `0xFD20`〜`0xFD27`のうちVOL(+0)、FEEDBACK(+1)、SHIFTLO(+3)、RELOAD(+4)、CTLA(+5)、CTLB(+7)だけ書く。OUT/DAC(+2)、COUNT(+6)は禁止。
- 停止/休符はVOL=0、CTLA=0。音程/波形変更時だけ公式順`CTLA=0 → SHIFTLO/CTLB/FEEDBACK → VOL → RELOAD → CTLA=(prescaler|0x18)`で再設定する。低音量、少数の固定波形/shift seed、`unsigned char`固定表を使う。
- Timer 0/2/7、`0xFD80`以降、channel B〜D、FD40〜44へ触れない。`CLI()`、75Hz、VBlank、`tgi_busy()`、TGIダブルバッファを変更しない。
